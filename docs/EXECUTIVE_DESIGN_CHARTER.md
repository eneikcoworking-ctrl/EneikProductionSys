## 1. ФУНДАМЕНТАЛЬНЫЙ ПРИНЦИП: ПОЧЕМУ «ГОЛЫЕ МОДЕЛИ» ДЕЛАЮТ ПЛОХОЙ ДИЗАЙН
Сырые LLM без жестких ограничений воспроизводят усредненный мусор из интернета:
- Фиолетовые градиенты и неоновые кнопки с размытыми тенями.
- Шаблонные 3-колоночные сетки с одинаковыми иконками в кружочках.
- Вымышленные футуристические надписи (Leica 50mm, GPS, STATUS: ONLINE).
- Центрированные абзацы текста без иерархии и случайные AI-лица.

**Хартия полностью запрещает этот подход.** Любой дизайн, создаваемый Фабрикой для любого проекта, подчиняется законам элитарной пространственной архитектуры.

## 2. АНТИ-СЛОП ФИЛЬТРЫ (КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО — FORBIDDEN)
1. **Запрет на дешевые AI-градиенты:** Никаких `from-purple-600 to-indigo-600` или радиоактивных свечений. Палитра строится на натуральных благородных материалах (глубокий обсидиан, шампанское золото, титан, лесная зелень).
2. **Запрет на псевдотехнический HUD-мусор:** Никаких характеристик оптики, выдуманных GPS-координат, фальшивых статусных бейджей, угловых скобок (corner brackets) и видоискателей.
3. **Запрет на шаблонные карточные сетки:** Запрещено делить страницу на одинаковые три квадрата с одинаковыми иконками. Композиция обязана быть динамичной и асимметричной (журнальная верстка).
4. **Запрет на синтетические стоковые лица:** Запрещено использовать вымышленные AI-аватары. Используются **только реальные студийные портреты персоны** (`portrait-hero.png`) в естественной цветопередаче (без обесцвечивания и фильтров contrast-125).
5. **Запрет на типографическую кашу:** Никакого центрирования длинных текстов, никаких фиксированных пикселей, ломающих масштабирование.

## 3. КАНОНЫ ДИЗАЙНА САЙТОВ-МИЛЛИОННИКОВ (ОБЯЗАТЕЛЬНО — OBLIGATORY)

### 3.1. Типографика как графический объект (Editorial Impact)
- Высокий динамический диапазон размеров: крупный, уверенный заголовок (`clamp(2.5rem, 6vw, 4.5rem)`) с отрицательным трекингом (`tracking-[-0.03em]`) и оптической подгонкой.
- Контраст с микро-типографикой: функциональные технические метки (`text-[11px] uppercase tracking-[0.18em] font-mono text-zinc-500`).
- Гарнитуры: `Geist` / `Inter` / `JetBrains Mono` для технологической четкости, либо благородный редакционный шрифт с засечками для академического достоинства.

### 3.2. Субпиксельные поверхности (Obsidian Micro-Surfaces)
- Многоуровневый темный режим:
  - Базовый холст: глубокий обсидиан `#08090C` / `#0C0E12`.
  - Приподнятые карточки: `#11141C` / `#161922`.
  - Субпиксельные границы: `border-white/[0.07]` (1px hairline) — деликатное разделение плоскостей без кричащих линий.
  - Мягкая диффузная глубина: деликатное рассеивание света `box-shadow: 0 0 0 1px rgba(255,255,255,0.06), 0 20px 40px -15px rgba(0,0,0,0.7)`.

### 3.3. Журнальная асимметрия и воздух (Swiss Grid & Space)
- Воздух (whitespace) — это активный элемент роскоши, а не пустое место.
- Асимметричные соотношения колонок (например, 7/5 или 8/4): доминирующий визуальный блок с аутентичным портретом уравновешивается плотным смысловым блоком с фактами, тезисами и кнопками целевого действия.

### 3.4. Достоинство студийного портрета
- Реальная фотография подается в премиальном архитектурном обрамлении: лаконичный радиус скругления (`rounded-2xl` / `rounded-3xl`), тонкий световой ободок (`ring-1 ring-white/10`), естественные теплые тона кожи и мягкая тень.

### 3.5. Тактильные микро-взаимодействия и мобильная эргономика
- Интерактивные элементы обязаны иметь тактильный отклик (`active:scale-[0.98] transition-all duration-150`).
- На мобильных устройствах (375px) ключевые действия находятся в зоне большого пальца (Thumb Zone, 44px+ hit targets), горизонтальный скролл категорически запрещен.
